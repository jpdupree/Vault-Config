📂 Load Real Vault Data

This dashboard ships with sample data. To document a real environment, load a configuration JSON file with 📂 Load Data (top right). It accepts this dashboard's own exported JSON and raw Vault API output. Generate that JSON from your Vault by running the included Export-VaultConfig.ps1 PowerShell script against your ADMS/Vault server, then load the resulting file here. Your data is kept only in this browser (💾 Save / ↺ Reset) — nothing is uploaded.
