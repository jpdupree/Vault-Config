📂 Load Real Vault Data

This dashboard ships with sample data. To document a real environment, load a configuration JSON file with 📂 Load Data (top right). It accepts three formats: a Vault .cfg Global Settings export (File ▸ Export in the Vault client), this dashboard's own exported JSON, and raw Vault API output. When you load a .cfg, an ⬇ Export .cfg button appears — it preserves that original package and patches your lifecycle edits back in so it re-imports into Vault. You can also generate JSON by running the included Export-VaultConfig.ps1 PowerShell script against your ADMS/Vault server, then load the resulting file here. Your data is kept only in this browser (💾 Save / ↺ Reset) — nothing is uploaded.

Tip: the Replace toggle (next to Load Data) controls how a file is applied — when on, any section missing from the file is cleared so only the file's data remains (a clean full replace); when off it merges, keeping current data for sections the file doesn't contain.
